# Trust by Example

Trust by Example is a practical, example-first guide to Trust: a language for
coordination systems, agent runtimes, durable workflows, capability-safe tools,
and replayable distributed execution.

This is an early documentation draft. Examples use the proposed Trust syntax and
should be treated as specification probes until the language checker and runtime
are implemented.
